# Source Authority Register

**Status:** Current operative authority register · **Last reviewed:** 2026-07-26
**Governing documents:** `docs/governance/SOURCE_AUTHORITY.md` (this register operationalizes it), `AGENTS.md`
**Related:** [Source Inventory](Source%20Inventory.md) · [Contradictions Matrix](Contradictions%20Matrix.md)

Authority is **claim-specific**: a source may control one topic while providing context only on another. This register states, for every material claim topic, which source controls, which provide context, and which are superseded. Model outputs never convert model inputs into verified facts. When two controlling-tier sources conflict within scope, the conflict is escalated — never averaged.

## Standing rules restated
1. Higher tier never extends a source beyond its scope (e.g., S1 outranks S2, but S1 says nothing about floor plates — so it cannot resolve OQ-14).
2. Where this register says **Unresolved/Escalated**, downstream documents must present both values with sources, or omit the topic — never pick silently.
3. When a missing document (MA-xx) is recovered, its scope rows here must be revisited before it is treated as controlling anything.
