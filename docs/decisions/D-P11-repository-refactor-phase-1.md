# D-P11 — Repository refactor Phase 1

**Decision.** Phase 1 may create directories, indexes, schemas, status headers, registers, structured exports, archive maps, validation scripts, templates, cross-links, generated-output boundaries, and plan-authorized moves of repository-authored documents with history preserved.

**Exclusions.** It may not alter original sources or workbook formulas/values; rewrite financial conclusions; select a story count or floor-plate basis; invent partner support or market rents; adopt tax credits; conceal the feasibility gap; or generate external marketing claims from unverified sources.

**Affected:** repository architecture and all Phase 1 implementation artifacts.

**Review trigger:** Phase 2 proposal, model-vNext work, source-file operation, or external-material creation.
